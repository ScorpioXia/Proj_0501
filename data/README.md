# 数据目录说明

本目录保存当前主线所需的源数据与冻结派生输入，程序只读，不会覆盖源文件。

- `labels/PATIENT_LIST_FILE.csv`：患者主表、动态不稳定标签和临床变量。原表共 849 行，其中 312 例有二分类标签（稳定 190、不稳定 122）。
- `features/features_312_20260722/`：分割模型生成的 2D、3D、跨层及审计后特征。当前 v11 的预设全局 MRI7 从 `muscle_features_3d_v7.csv` 直接构建。
- `annotations/`：30 例试验和 219 例节段标注；仅供历史节段实验或后续研究使用。
- `derived/v11_clinical_mri/`：为复现旧标签筛选 MRI7 而冻结的患者级特征宇宙和选择结果。

数据连接键统一为规范化 `patient_id`。不要以姓名、拼音或行号连接。患者级文件不应上传公共仓库。
