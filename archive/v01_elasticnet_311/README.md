# v01：ElasticNet基线实验（311例）

## 版本定位

- 规范版本：`v01_elasticnet_311`
- 原项目编号：v1
- 任务：建立首个患者级腰椎稳定性预测基线。
- 队列：311例，稳定189例、不稳定122例。

## 目录内容

- `code/`：特征构建、ElasticNet建模、配置、运行入口及依赖。
- `features/`：本版本使用的早期v6特征快照。
- `results/`：患者级特征宽表、外层OOF预测、逐折表现、特征选择频率、审计和图表。

## 实验内容

比较E1（3D/跨层/多肌肉）、E2（2D聚合）和E3（组合）三套特征。采用5折外层、4折内层嵌套交叉验证；填补、截尾、去冗余、Pearson Top-K、标准化和ElasticNet调参均在训练折内完成。

## 主要结果

- E1 3D：ROC-AUC 0.566。
- E2 2D：ROC-AUC 0.533。
- E3 组合：ROC-AUC 0.559。
- 三组模型的Brier分数均未优于患病率基线。

## 版本结论

本版本证明肌肉MRI可能包含弱信号，但尚不足以形成可靠预测模型。它确立了患者级OOF预测和训练折内预处理的基础规范。
