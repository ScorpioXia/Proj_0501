# v02：多模型比较与特征准确性审计（311例）

## 版本定位

- 规范版本：`v02_multimodel_311`
- 原项目编号：v2
- 任务：在v01基础上比较多种非线性模型，并系统审计特征提取质量。

## 目录内容

- `code/`：XGBoost、LightGBM、随机森林、RBF-SVM、EBM等建模代码及敏感性分析入口。
- `results/formal_v6/`：15组模型×特征集的正式嵌套CV结果。
- `results/sensitivity_v6/`：删除可疑字段后的事后敏感性分析。

## 实验内容

在相同311例和相同外层划分上比较5种模型与3套特征。所有预处理和调参仍在训练折内完成，同时核查面积、FIP、3D统计范围、纹理重复和异常比例字段。

## 主要结果

- 表观最佳为LightGBM+2D：AUC 0.583。
- 删除可疑`Solidity`和`Deep_Fat_Ratio`相关特征后，LightGBM AUC降至约0.527。
- 多数模型存在明显训练—验证差距，未证明复杂模型优于ElasticNet。

## 版本结论

本版本最重要的成果不是更高AUC，而是发现早期特征中的公式/映射风险，并明确后续应优先修复特征提取。
