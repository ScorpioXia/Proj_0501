## 实验内容

预先锁定三组候选：

- LightGBM + 2D (`E2_2d`)
- XGBoost + combined 2D/3D (`E3_combined`)
- ElasticNet + 3D (`E1_3d_level3`)

验证设计为10个随机种子×5折外层×4折内层，每个候选获得50个独立外层测试预测。

- 预设10个重复随机种子：2026至2035。
- 每次重复包含5折分层外层验证和4折内层调参。
- 每个候选模型共得到50组独立外层测试预测。
- 主要估计为10次重复患者级OOF指标的均值，并使用患者与重复层级Bootstrap计算置信区间。

## 主要结果

- ElasticNet+3D：平均AUC 0.572。
- XGBoost+组合：平均AUC 0.564。
- LightGBM+2D：平均AUC 0.556；v03的0.596是其重复结果最大值。

## 版本结论

没有模型达到稳定高判别能力，但本版本显著提高了结果可信度，并推翻了“LightGBM明显更优”的单次划分印象。
