# v05：Pearson筛选与旋转因子分析（312例）

## 版本定位

- 规范版本：`v05_factor_analysis_312`
- 原项目编号：v5
- 完成时间：2026-07-23。
- 输入：601个2D/3D组合特征。

## 目录内容

- `code/`：训练折内Pearson筛选、varimax因子分析、重复嵌套CV和阈值审计。
- `results/v5_factor_analysis/`：阈值可行性、因子载荷、OOF预测、稳定性及汇总结果。

## 实验内容

每个训练分区内以`abs(r)>=0.15`筛选特征，再构建3/5/8/10个varimax因子，并通过内层CV选择因子数和模型参数。比较ElasticNet、XGBoost和LightGBM。

原定0.25阈值在48/50个外层训练折中选不出特征，因此记录审计后改为0.15。

## 主要结果

- ElasticNet AUC 0.570。
- XGBoost AUC 0.564。
- LightGBM AUC 0.554。
- 相对v04没有实质性判别提升，但输入维度和解释性改善。

## 版本结论

结果支持“弱而分散的MRI信号”，不支持因子分析能制造显著预测增益。
