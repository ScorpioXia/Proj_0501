# v07：紧凑节段面板验证（219例）

## 版本定位

- 规范版本：`v07_segment_validation_219`
- 原项目结果目录：`v7_segment_validation_219`
- 主要确认队列：未参与v06设计的189例；全219例为敏感性分析。

## 目录内容

- `code/`：20层解剖映射、紧凑面板构建、重复嵌套CV及入口。
- `results/`：注释快照、16项面板、6项梯度、逐折/逐患者结果、系数稳定性和警告。

## 实验内容

比较全局16项、目标节段16项及目标节段+6个尾侧梯度。使用10次×5折外层、4折内层CV，不进行监督特征选择。

## 主要结果

- 189例全局AUC 0.504。
- 目标节段AUC 0.541。
- 目标+梯度AUC 0.577；相对全局提高0.073，但CI跨0。

## 重要限制

219例解剖层面由患者77的20层模式复制推断，并非逐患者影像确认；这是本版本最主要的数据风险。
