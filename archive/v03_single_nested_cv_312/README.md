# v03：v7特征单次嵌套交叉验证（312例）

## 版本定位

- 规范版本：`v03_single_nested_cv_312`
- 原项目编号：v3
- 完成时间：2026-07-22。
- 队列：312例，稳定190例、不稳定122例。

## 目录内容

- `code/`：当时的完整代码、配置、入口和依赖快照。
- `results/formal_v7_run_01/`：单个随机种子的正式结果。
- `results/validation_only/`：运行前的数据与特征审计结果。

## 实验内容

采用随机种子2026的一次5折外层、4折内层嵌套CV，比较ElasticNet、XGBoost和LightGBM在3D、2D及组合特征上的9种组合。

## 主要结果

- 表观最佳：LightGBM+2D，AUC 0.5958。
- 该数值后来证实是10次重复结果中的最高值。

## 版本结论

单次随机划分不足以支持模型优劣判断，因此下一版本升级为重复嵌套交叉验证。
