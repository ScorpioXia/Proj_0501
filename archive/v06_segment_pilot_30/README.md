# v06：目标节段定位可行性试验（30例）

## 版本定位

- 规范版本：`v06_segment_pilot_30`
- 原项目结果目录：`v6_segment_pilot_test30`
- 队列：30例，其中不稳定7例，全部主要滑脱节段为L4。

## 目录内容

- `code/`：节段注释对齐、目标/相邻/全局特征构建、重复嵌套CV入口与依赖。
- `results/`：四套特征面板、逐患者OOF预测、配对比较、特征稳定性和审计。

## 实验内容

比较全局、目标节段、目标+相邻节段和机制组合特征。采用30次重复3折外层、2折内层CV和带类别平衡的L2 Logistic回归。

## 主要结果

- 全局特征AUC 0.416。
- 目标节段AUC 0.615。
- 目标+相邻AUC 0.571。
- 目标相对全局提高0.199，但95%CI跨0。

## 版本结论

目标定位方向值得扩大样本验证，但7个阳性病例不足以形成确证结论。
