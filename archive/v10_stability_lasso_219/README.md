## 实验内容

## 主要结果

- 严格流程最佳SVM AUC 0.442。
- 全队列先筛选的无效结果可达到0.633–0.659。
- 泄漏使AUC人为增加约0.194–0.238。
- 多裂肌3D体积不对称是跨外层训练折最稳定的候选，但保留频率也仅0.66。
