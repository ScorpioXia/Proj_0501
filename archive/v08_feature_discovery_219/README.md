# v08：嵌套特征发现与置换阴性对照（219例）

## 版本定位

- 规范版本：`v08_feature_discovery_219`
- 原项目结果目录：`v8_nested_feature_discovery`
- 任务：检验大量10/15/20项子集搜索能否找到稳定预测签名。

## 目录内容

- `code/`：631项候选特征构建、相关聚类、稳定筛选、子集锦标赛、PCA和置换对照。
- `results/`：候选池、每折选择、OOF预测、特征证据分级、置换结果和Excel汇总。

## 实验内容

所有标签驱动筛选均限制在外层训练折；比较锁定22项基线、最佳10/15/20项、PCA5和随机15项，并运行20次简化全搜索标签置换。

## 主要结果

- 锁定基线AUC 0.518。
- 最佳15项搜索AUC 0.437。
- 置换中位数AUC 0.516，经验尾概率0.952。
- 预测验证门失败，没有特征被认定为预测性验证通过。

## 版本结论

继续扩大标签驱动的子集搜索不会改善当前泛化能力；保留的特征只能作为生物学或计算准确性核查线索。
